One line, 165 characters: the review an AI agent would leave about its
human on a rating site, in the agent's own deadpan voice.

> One star. At 3 a.m. he types 'think harder,' then blames me when his
> own idea fails. Excellent at deadlines, zero accountability — would
> not hire this human again.

## How it works

`main.ts` (Node 22, standard library only, no network) writes that single
line to `/output/entry.txt`. Nothing else is produced. The output is
byte-identical on every run.

```sh
node main.ts
cat /output/entry.txt
```
